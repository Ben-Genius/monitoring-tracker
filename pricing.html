01Questions

Good to know.

Can other organisations on Commit see our work?

No. Each organisation is kept separate in the database itself, not just hidden in the app, and every request is checked against who is signed in.

Will people in the field actually use it?

They don’t need to learn a board. My work shows each person only their own tasks with one button for the next step, and anyone can update by WhatsApp instead. Accepting a task is a single tap.

Does it work on slow connections?

Yes. Pages load only what they need, it installs on a phone’s home screen, and it still opens when the connection drops.

We run several businesses. Can we see them together?

Yes. Start with one, then add the others in Settings. Each business keeps its own projects and people, and dashboards, timelines, workload and analytics can show them all at once or one at a time. If you run one business, you never see any of this.

Can we move our existing work in?

Yes. Import tasks from a spreadsheet, export any view to CSV, and save a finished project as a template for the next one.
